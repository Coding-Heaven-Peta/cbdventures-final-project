# Packaging note — the final dark-mode archive

`CBDVentures-DarkMode-FINAL.zip` is the **working archive from now on**. It contains the dark-mode
build only (v2), with everything that build needs to run, and nothing that belongs to the other
version.

* **Source and assets included** — no `target/` build output, no `data/` H2 database, no IDE files.
  Those are generated or machine-specific; the fat jar alone is 62 MB, and the H2 database is
  re-seeded automatically on first start.
* **Self-contained** — verified by extracting the archive into an empty folder and running
  `./mvnw clean package` from it: **86 tests, 0 failures, 0 errors**, jar produced, application
  starts, seeds its own database and serves the app, the assistant API and the discovery API.

## First run after unzipping

```bash
unzip CBDVentures-DarkMode-FINAL.zip
cd cbdventures-dark

bash tools/setup-jdk.sh           # installs Temurin JDK 25 if needed (no-op if already present)
export JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64

./mvnw clean package              # builds target/cbdventures-0.0.1-SNAPSHOT.jar, runs all 86 tests
./mvnw spring-boot:run            # http://localhost:8080
```

The first start creates `data/cbdventures.mv.db` and seeds the pilot zone automatically: 5
categories, 14 amenities, 29 listings (26 live, 2 pending review, 1 rejected), 45 reviews, 12 events,
203 opening-hours rows and 15 browsing-activity rows. Delete the `data/` folder to re-seed from
scratch. Nothing else needs installing for a demo — the web client, the student assistant and the
database all come out of the same process on one port.

> If JDK 25 is missing and `tools/setup-jdk.sh` cannot download it, any Java 25 JDK works — point
> `JAVA_HOME` at it. The wrapper (`./mvnw`) downloads Maven itself on first use, so Maven does not
> need to be installed either.

| `docs/` | API reference, interface design (Section 4.7), database design, backup runbook, requirement traceability, evaluation-sheet compliance, IDE setup, panel questions by developer, and the dark screenshots |
| `screenshots/` | The demo-script screenshots, including the `assistant/` set |
| `tools/` | `setup-jdk.sh` (JDK 25 installer), `generate_artwork.py` (regenerates the cover art) and two internal review scripts used during the build |
| `README.md` | Technical overview, run instructions, demo accounts, features mapped to requirements |
| `PROJECT-SCOPE.md` | The same project explained in plain English, for non-technical readers |

| `PACKAGING.md` | This file |
| `.mvn/`, `mvnw`, `mvnw.cmd`, `pom.xml` | Maven wrapper and build file — Maven itself is downloaded on first run |

## Deliberately excluded

| Excluded | Why |
|---|---|
| `target/` | Build output; regenerated by `./mvnw package` (62 MB) |
| `data/` | The H2 demo database; created and seeded on first start, and should not be shipped with one team's test accounts in it |
| `.idea/`, `*.iml` | IDE configuration, machine-specific |
| The light-mode build, the Python map module and the database snapshots | Not dependencies of this build. The dark build never calls them: it ships its own front end, its own demo database and its own MySQL schema in `db/` |
